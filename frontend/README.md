# Frontend

Responsive React/TypeScript dashboard for Northstar Retail BI.

```powershell
npm ci
npm run dev
```

In development, the app reads the Vite-only `/__local/dashboard.json` endpoint backed by the ignored `data/local/dashboard.json` file. Generate the synthetic POS aggregates from the repository root with:

```powershell
.\.venv\Scripts\python.exe -m retail_bi.pos_pipeline --local-export
```

Production builds never expose that endpoint or copy the local file. Production reads `/data/dashboard.json`, generated by the CC BY-verified `retail_bi.pos_pipeline --publish-export` workflow. Both modes contain KPI, monthly, category, store, and discount-band aggregates, limited to three simultaneous filters and a 10-transaction minimum. Transaction IDs, customer IDs, products, and line-item rows are excluded.
