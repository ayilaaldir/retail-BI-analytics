# Frontend

Responsive React/TypeScript dashboard for Northstar Retail BI.

```powershell
npm ci
npm run dev
```

In development, the app reads the Vite-only `/__local/dashboard.json` endpoint backed by the ignored `data/local/dashboard.json` file. Generate it from the repository root with:

```powershell
.\.venv\Scripts\python.exe -m retail_bi.pipeline --source "data/raw/Sample - Superstore.csv" --local-export
```

Production builds never expose that endpoint or copy the local file. Production reads `/data/dashboard.json`, which can only be generated by the license-gated `--publish-export`. If the applicable file is absent, the app presents the no-data onboarding state without placeholder KPIs.
