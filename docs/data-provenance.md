The versioned Mendeley record and accompanying documentation describe the source as fully synthetic, generated by a seeded Python simulation, with no real customer, personal, or business data. It reproduces a documented POS export structure but is not affiliated with or endorsed by Square or Block, Inc.

## License evidence

Mendeley Data labels Version 1 as **CC BY 4.0**. The [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/) license permits sharing and adaptation provided appropriate credit is given, the license is linked, and changes are indicated.

The Northstar export is an adaptation: it validates and normalizes the source, creates a Parquet analytical layer and DuckDB views, and publishes only disclosure-controlled aggregates. The original archive and line-level records are not redistributed by this repository.

The dashboard footer links both the source record and the license and indicates that the data was adapted.

## Publication decision

The public-license evidence is sufficient for a proposed aggregate browser export. The manifest records:

- `license_verified: true`;
- `redistribution_status: permitted`;
- the Mendeley versioned record and exact file checksum; and
- the canonical CC BY 4.0 URL.

This license verification permits generating `frontend/public/data/dashboard.json` for inspection. It is not approval to commit, push, or deploy the migration. Those actions remain subject to explicit repository-owner approval.

## Data minimization

The browser asset excludes transaction IDs, customer IDs, item names, SKUs, price-point names, device names, time-of-day, and transaction rows. It includes only source metadata, filter options, and aggregate KPI/month/category/store/discount views. Published aggregates require at least 10 transactions and no more than three simultaneous filter dimensions.
